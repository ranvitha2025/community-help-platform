# Community Help Platform 🌍

A full-stack web platform that connects community members with volunteers to solve local problems efficiently.

## 🚀 Features

- 📝 Report local problems
- 👷 Volunteer registration
- 📍 Area-based volunteer matching
- 🤖 Auto assignment of volunteers
- ✅ Problem completion tracking
- 🌐 3 language support (English, Kannada, Hindi)

## 🛠️ Tech Stack

| Frontend | Backend | Database |
|----------|---------|----------|
| HTML | Node.js | MongoDB Atlas |
| CSS | Express.js | |
| JavaScript | PM2 | |

## 📁 Project Structure

- `index.html` — Home page
- `Dashboard.html` — Volunteer registration
- `report.html` — Problem reporting
- `volunteers.html` — Available volunteers
- `assignment.html` — Assign volunteers
- `Completed.html` — Completed problems
- `help.html` — Help and support
- `server.js` — Backend server
- `api.js` — API functions
- `nav.js` — Navigation and language switcher
- `style.css` — Styling

## ⚙️ How to Run

1. Clone the repository
2. Run `npm install`
3. Add MongoDB connection string in `server.js`
4. Run `node server.js`
5. Open `index.html` with Live Server

## 🔄 How It Works

1. User reports a problem with their area
2. System finds volunteers in the same area
3. Admin assigns a volunteer
4. WhatsApp notification sent to volunteer
5. Admin marks problem as completed
6. Volunteer becomes available again
